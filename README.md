# دیدبان · Didban AI Trader

دستیار ترید دسکتاپ (ویندوز و مک) با رابط گرافیکی، تحلیل لحظه‌ای با اندیکاتورها + هوش مصنوعی، و ربات خودکار متصل به صرافی.

> ⚠️ هیچ رباتی سود تضمینی ندارد. همیشه اول با **حساب تست داخلی** یا **تست‌نت** کار کنید. کلید API را فقط با دسترسی «ترید» بسازید، هرگز «برداشت».

## امکانات (نسخه 0.3)
- پنجره شروع با سه سبک: **نوسان‌گیری (4h)**، **روزانه (15m)**، **بلندمدت (1d)**. هر سبک تایم‌فریم، EMA، حد سود و ضرر و افق پیش‌بینی خودش را دارد
- صرافی‌ها از طریق `ccxt`: Binance، KuCoin، Toobit، Bybit، OKX، Bitget، Gate، MEXC + حالت **Demo آفلاین**
- بازار اسپات، مارجین و فیوچرز با **اهرم** (تا 125x)، مارجین ایزوله/کراس
- انتخاب **یک یا چند ارز** برای ربات (تیک در واچ‌لیست)
- چارت کندلی با EMA و RSI؛ **حد سود، حد ضرر، ورود و قیمت لیکوئید** هنگام باز شدن پوزیشن روی چارت رسم می‌شود
- همه پنل‌ها و چارت‌ها **جابجا، ریسایز، شناور و تب‌شونده**‌اند و چیدمان ذخیره می‌شود. چند چارت هم‌زمان (دوبار کلیک روی نماد)
- **حساب تست داخلی** با موجودی دلخواه، کارمزد، لیکوئیدیشن، وین‌ریت و افت سرمایه
- مدل هوش مصنوعی (Gradient Boosting) که روی داده‌های اخیر هر ارز آموزش می‌بیند و با رأی اندیکاتورها (EMA، MACD، RSI، ADX، Bollinger، ATR) ترکیب می‌شود
- مدیریت ریسک: درصد ریسک هر معامله، حداکثر پوزیشن باز، توقف خودکار در افت

## اجرا
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

با push یک تگ (مثلاً `git tag v0.3.0 && git push --tags`)، GitHub Actions فایل‌های `Didban-windows.zip` و `Didban-macos.zip` را می‌سازد و در Releases می‌گذارد.

## تغییرات 0.3
- تایم‌فریم کاملاً آزاد: لیست آماده + هر مقدار دلخواه (مثلاً 7m، 45m، 3h، 2d). اگر صرافی مستقیم نداشته باشد، از تایم‌فریم کوچک‌تر ساخته می‌شود
- اتصال API: کلید را در پنجره «🔑 API صرافی» وارد و تست کن. کلیدها در Keychain سیستم ذخیره می‌شوند
- چارت: کشیدن برای دیدن کندل‌های گذشته، اسکرول برای زوم، کشیدن محور قیمت برای کشش عمودی، و تاریخچه‌ی بیشتر به‌صورت خودکار
- انتخاب موتور هوش مصنوعی: اندیکاتور خالص، چهار مدل محلی (Gradient Boosting، Random Forest، Extra Trees، Logistic Regression)، و LLM‌ها (OpenAI، Claude، Gemini، DeepSeek، Grok، OpenRouter، Ollama)
- واچ‌لیست با ۳۲ ارز معروف + جستجو و افزودن هر بازاری از صرافی

## محدودیت‌های فعلی
- معامله واقعی و تست‌نت آزمایشی است؛ SL/TP به‌صورت سفارش متصل ارسال می‌شود ولی همگام‌سازی کامل پوزیشن‌های صرافی هنوز پیاده نشده
- پشتیبانی Toobit به نسخه نصب‌شده ccxt بستگی دارد
- LLM‌ها فقط یک بار در هر کندل جدید صدا زده می‌شوند؛ هزینه‌ی API با خود ارائه‌دهنده است
