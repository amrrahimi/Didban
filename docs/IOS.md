# iPhone version

- **Code**: `ios/shared` is a Kotlin Multiplatform build (framework `PokerCore`) compiled from the same
  sources as Android (`core/model`, `core/poker`, `core/domain/.../vision`) plus an iOS facade
  (`LiveSession`, `PhotoScan`, `MemoryStore`, `Advisor`). `ios/app` is the SwiftUI app; the Xcode project
  is generated by XcodeGen from `project.yml`. The card model is the same ONNX file, run with ONNX Runtime.
- **Features (v0.9)**: live table with photo scan (whole photo + tiles), tap-to-correct and tap-to-teach
  card memory, multi-select manual picker, manual mode (camera off), camera only on before a photo,
  advice for all six variants, Persian/English switch. Not yet on iPhone: Monitor mode, Learn Deck,
  history, settings screens.
- **Build**: `.github/workflows/ios.yml` on `macos-15`: shared Kotlin tests on the iOS simulator, XCFramework,
  unsigned Release build, `PokerVisionAI.ipa` published to the `poker-vision-ios-latest` release.
- **Install without the App Store**: sign with the user's Apple ID using Sideloadly or AltStore (Windows needs
  iTunes and iCloud from apple.com, not the Microsoft Store). Free Apple ID: re-sign every 7 days; paid
  developer account: 1 year. iOS 16+ needs Developer Mode.
- **Not verified**: the app has only been built on CI, not run on a real iPhone yet.
